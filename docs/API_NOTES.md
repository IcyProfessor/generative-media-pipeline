## Gemini

Используется пакет `google-genai`, не старый `google-generativeai`. Адаптер принимает общий Prompt и Pydantic-схему, запрашивает JSON, проверяет ответ и сохраняет usage metadata, если SDK её вернул. Встроенные попытки SDK ограничены одной; ошибка схемы не запускает скрытую регенерацию.

Default `gemini-3.5-flash-lite` выбран как конфигурируемая отправная точка, не как результат сравнения качества. Модель/доступность нужно проверить через `list-models` и короткий `smoke-gemini`. Не делаем вывод об аккаунтном доступе по одному названию модели.

Источник: https://ai.google.dev/gemini-api/docs/deprecations
SDK: https://pypi.org/project/google-genai/

## SunoAPI — сторонний поставщик

Это интеграция с **sunoapi.org**, не утверждение о наличии официального API компании Suno. Перед передачей ключа убедитесь, что base URL соответствует кабинету, где вы покупали кредиты. В примере используется `https://api.sunoapi.org/api/v1`.

В просмотренной спецификации custom vocals используют `customMode=true`, `instrumental=false`, `prompt` с текстом песни, `style`, `title`, `model`, `callBackUrl`. Список документированных моделей включает `V5` и `V5_5`; автоматическое предположение исходника про `V6 → lyrics/duration` не подтверждается этой страницей.

Поэтому в RC:

```yaml
suno:
  model: V5
  request_format: prompt
  include_duration: false
```

`duration` в просмотренной документации доступен для `V5_5` в custom mode. Для явного запроса используйте `model: V5_5` и `include_duration: true`; адаптер отвергнет эту настройку на другой модели документированного профиля до отправки. Поле `audio.duration_seconds` само по себе не ограничивает длину любого ответа модели.

Для восстановления конкретного старого аккаунтного контракта сохранён **опциональный** `request_format: legacy_lyrics`, отправляющий `lyrics`/`duration`. Этот режим не объявлен актуальным или проверенным. Включать его следует только после сверки со своим поставщиком, не потому что так делал старый код.

Источники:
https://docs.sunoapi.org/suno-api/generate-music
https://docs.sunoapi.org/suno-api/get-music-generation-details
https://docs.sunoapi.org/suno-api/get-timestamped-lyrics

## Запросы и ошибки

Polling — GET с ограниченными повторениями при transport/5xx; POST генерации и POST выравнивания не повторяются автоматически. HTTP-код и бизнес-код ответа проверяются отдельно. Пустой/неизвестный статус, неверный JSON, пустые/дублирующиеся кандидаты не трактуются как готовый результат.

`SunoAlignment` преобразует `alignedWords` в `Transcript`; downstream не разбирает формат поставщика. Raw-response для транскрипции не становится общим контрактом системы.

Аудио скачивается отдельным HTTP-клиентом **без Authorization генератора**, включая переходы между CDN. Есть предел размера и количества redirects. HTTPS/private-literal-IP проверки уменьшают случайные ошибки конфигурации; полноценной DNS-rebinding/SSRF песочницы для недоверенного многопользовательского сервиса здесь нет.

API-ошибки сокращены, чтобы не выводить сырые ответы, ключи и signed URLs. Локальный `job.json` всё равно содержит нужную для скачивания ссылку кандидата: не публикуйте production output вместе с репозиторием.

## Callback

Polling не отменяет обязательное поле `callBackUrl` в спецификации. Нужен endpoint, который контролирует владелец. В RC нет публичного webhook-сервера, tunnel-менеджера или обработки callback. Не подставляйте чужой endpoint ради обхода preflight.

## Изменения адаптеров rc2

Structured generation использует `response_json_schema` и отключённый automatic function calling. Локальная Pydantic-валидация остаётся обязательной. Конвертер не удаляет имена полей, случайно совпавшие с ключевыми словами JSON Schema.

Неоднозначные transport/business outcomes не считаются доказанным отказом. V3_5/V4 используют лимит текста 3000 и style 200 символов. Новую модель следует сверять со спецификацией поставщика, а не угадывать формат по названию. Платные вызовы в аудите не выполнялись.
